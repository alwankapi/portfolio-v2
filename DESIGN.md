# Design Direction

## Identity
- **Owner**: Alwan Kapi Muntaha (Awank)
- **Role**: Web Developer · Program Analyst · UI/UX Designer
- **Tone**: Clean, authentic, engineering-grounded, human.

## Aesthetics
- **Theme**: Minimal monochrome base with purposeful warm/amber/orange accents for interactive elements.
- **Background**:
  - Light mode: Pure/warm whites with subtle border contrasts (`border-border`).
  - Dark mode: Deep neutral black (`hsl(240 10% 3.9%)`), crisp borders, subtle glows.
- **Typography**: Inter / sans-serif, tight tracking on headings (`tracking-tighter`), readable line-heights.
- **Components**: Magic UI subtle canvas animations, clean cards, rounded badges, no bloated decorations.
- **Copy**: Direct, conversational, honest. No buzzwords, no inflated claims.
